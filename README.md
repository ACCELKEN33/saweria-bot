# Saweria Discord VIP Bot

Cara menjalankan project ini:
1. Ekstrak folder ini ke komputer kamu.
2. Buka folder ini di Visual Studio Code (VS Code).
3. Buat terminal baru di VS Code dan jalankan perintah:
   ```bash
   npm install
   ```
4. Masukkan Token bot Discord kamu ke dalam file `.env`.
5. Jalankan server dengan perintah:
   ```bash
   node index.js
   ```
6. Gunakan Ngrok untuk menghubungkan webhook Saweria ke `http://localhost:3000/webhook/saweria`.
